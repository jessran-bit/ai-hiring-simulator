# AI Hiring Simulator: Biased vs Clean Data

This is a simple classroom/demo app that shows how algorithmic bias can affect hiring outcomes.

## What it demonstrates
- AI systems can produce unfair outcomes even without directly using gender
- Proxy variables can still introduce bias
- Small scoring choices can have major effects on ranking candidates

## Files
- `app.py` - Streamlit app
- `data/candidates_biased.csv` - candidate data
- `data/candidates_clean.csv` - same candidate data, used with cleaner scoring logic
- `requirements.txt` - dependencies
